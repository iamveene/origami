# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.5.x   | Yes       |
| < 0.5   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in Origami, please report it responsibly.

**Email:** [mv@archsec.io](mailto:mv@archsec.io)

**Please include:**
- A description of the vulnerability
- Steps to reproduce
- Affected version(s)
- Impact assessment (if possible)

**What to expect:**
- Acknowledgement within 48 hours
- Status update within 7 days
- We will coordinate disclosure timing with you

## Scope

The following are in scope:
- The Origami browser extension (this repository)
- The Origami MCP server (`mcp-server/`)
- Plugin system and sample plugins (`plugins/`)

The following are **out of scope:**
- Third-party APIs (OpenAI, Anthropic, Google, Ollama)
- Websites you scan with Origami
- Chrome Web Store infrastructure

## Disclosure Policy

- Please do **not** open public GitHub issues for security vulnerabilities
- We follow coordinated disclosure — fixes are released before details are made public
- Credit is given to reporters unless they prefer to remain anonymous
